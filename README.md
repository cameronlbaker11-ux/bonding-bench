# Bonding Bench

A chemistry sandbox in a single HTML file: every element, bonds that form and break by the physics, reactions written up with equations and energies, a 3D bench, and a Learn mode that walks through one reaction at a time.

**Live:** https://cameronlbaker11-ux.github.io/bonding-bench/

## Use it on another site

```html
<iframe src="https://cameronlbaker11-ux.github.io/bonding-bench/"
        style="width:100%;height:90vh;border:0" allow="fullscreen"></iframe>
```

Or copy `index.html` onto your own server: it has no build step and no dependencies beyond web fonts.
